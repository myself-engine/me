# me v0.9.7

짧은 작업 요청을 채팅 질문으로 잘못 처리하지 않고, 필요한 작업은 실제 작업 흐름으로 넘깁니다. 릴리스 노트를 이전 릴리스 이후 변경된 내용을 바탕으로 작성할 수 있습니다.

## 새로 생긴 것

- 짧은 작업 요청도 작업 의도를 판정해 필요한 경우 위임 흐름으로 보냅니다. 단순한 인사와 정보 질문은 기존처럼 바로 답합니다.
- `me release notes`로 릴리스 노트 초안을 별도로 만들 수 있습니다. 미리보기만 하거나, 가벼운 첫 문장 변경을 선택할 수도 있습니다.

## 고친 것

- 작업 요청을 채팅으로 잘못 분류해 작업이 진행되지 않거나, 도구가 없다는 안내만 반환하던 문제를 고쳤습니다. 이제 해당 요청은 작업 흐름으로 전달됩니다.
- 릴리스 노트 생성에 실패해도 확인 가능한 커밋 내용을 바탕으로 절차를 계속할 수 있습니다.

## 알아둘 것

- 릴리스 노트에는 이전 릴리스 이후의 커밋과 결정 기록에 새로 추가된 내용만 반영됩니다.
- 릴리스 노트 초안 작성은 Git 기록을 바꾸지 않습니다.
