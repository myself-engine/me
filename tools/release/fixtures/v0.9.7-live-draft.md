me v0.9.7에서는 짧은 입력을 더 정확히 구분해 인사와 정보 질문에는 바로 답하고, 작업 요청은 작업 흐름으로 넘깁니다. 릴리스 노트는 이전 릴리스 이후의 변경 근거를 바탕으로 작성할 수 있습니다.

## 새로 생긴 것

- 짧은 작업 요청도 채팅으로 잘못 처리하지 않고 작업 흐름으로 넘깁니다.
- `me release notes --from <태그> [--to <태그|HEAD>]`로 릴리스 노트 초안을 따로 만들 수 있습니다. `--dry-run`을 사용하면 노트만 확인할 수 있습니다.

## 고친 것

- 짧고 애매한 입력을 성급히 일반 대화로 분류하거나, 작업을 처리할 수 없다고 잘못 안내하는 문제를 고쳤습니다.

## 알아둘 것

- `me release notes`는 노트 초안만 만들며 Git 기록을 바꾸지 않습니다.
