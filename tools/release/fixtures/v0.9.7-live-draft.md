In me v0.9.7, short inputs are classified more accurately: greetings and information questions get direct answers, while work requests enter the task flow. Release notes can be drafted from evidence since the previous release.

## New

- Short work requests enter the task flow instead of being mistaken for chat.
- `me release notes --from <tag> [--to <tag|HEAD>]` drafts release notes separately. `--dry-run` previews the notes only.

---

me v0.9.7에서는 짧은 입력을 더 정확히 구분해 인사와 정보 질문에는 바로 답하고, 작업 요청은 작업 흐름으로 넘겨요. 이전 릴리스 이후의 근거로 노트 초안도 만들 수 있어요.

## 새로 생긴 것

- 짧은 작업 요청을 채팅으로 잘못 분류하지 않고 작업 흐름으로 넘겨요.
- `me release notes --from <태그> [--to <태그|HEAD>]`로 노트를 따로 만들 수 있고, `--dry-run`으로 초안만 확인할 수 있어요.

## 고친 것

- 짧고 애매한 입력을 성급히 대화로 분류하거나 작업을 처리할 수 없다고 안내하던 문제를 고쳤어요.

## 알아둘 것

- `me release notes`는 초안만 만들며 Git 기록은 바꾸지 않아요.
